Seladora Printer Pro

Selagem com rastreabilidade total, impressora integrada e sistema touch screen.

Equipamentos

Tecnologia e Rastreabilidade

A Seladora Printer Pro combina selagem de alta qualidade com um sistema avançado de rastreabilidade. Com tela touch screen de 2.8" e microprocessador dedicado, garante controle total do processo e emite etiquetas com dados da esterilização.

Características Principais

  • Tela: Touch screen 2,8"
  • Rastreabilidade: Impressão de etiqueta autocolante para cada selagem
  • Controle: Microprocessador dedicado com 3 programas
  • Stand By: Automático para economia de energia
  • Segurança: Selagem somente com temperatura atingida

Especificações Técnicas

  • Largura Selagem: 13mm
  • Temperatura: 60 °C a 200 °C
  • Alimentação: 220 Vac / 60 Hz (270 Va)
  • Material: Aço Inox 304
  • Dimensões Seladora: 390 x 255 x 250 mm
  • Dimensões Impressora: 180 x 260 x 180 mm
